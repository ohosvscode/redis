# HNP 编译示例

这是一个简单的 HarmonyOS Native Package (HNP) 编译示例项目。

## 文件说明

- `main.c` - 示例 C 程序源代码
- `build.sh` - 编译脚本
- `CMakeLists.txt` - CMake 构建配置（可选）
- `package.json` - 包配置（参考）
- `my_hnp_project.hnp` - 编译生成的 HNP 包

## 使用方法

```bash
cd examples/hnp_example
./build.sh
```
